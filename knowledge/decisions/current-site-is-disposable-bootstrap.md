The current Atlas website is a quick visualization and self-description test. It is not yet a proper or approved Atlas product experience. Its visual language, page structure, information architecture, record vocabulary, and implementation may be substantially changed or discarded as Atlas is developed.

Preserve the useful test: Atlas should be able to describe Atlas, including its own design and technical machinery, using the knowledge it stores. Do not treat the current HTML and styling as the answer to that product-design problem.
