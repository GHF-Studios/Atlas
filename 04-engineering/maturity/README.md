# Maturity

> **Status:** Draft — proposed canonical stage vocabulary; criteria are not adopted yet.

Define a small shared vocabulary for pre-alpha, alpha, beta, and release, with explicit evidence and scope for each stage. A stage should describe readiness for a stated purpose, not the maturity of every dimension of a product.

Planning should use these terms only as references; dated milestones belong in Planning and product-specific evidence belongs in each product's Current State. Avoid implying that a stage label alone is approval.
