# Engineering

This section documents how we design, implement, integrate, test, debug, review, and release software, including the reasons behind those practices.

## Current state — 2026-11-11

There is substantial real code and hard-won engineering experience, but many architectural boundaries are still moving.
Work is deliberately fast and refactor-heavy during pre-alpha. Practices are not yet uniform across repositories; in Loo Cast, some behavioral validation is still explicitly manual.
We should document what we actually do, not invent the procedures of an established engineering department.
