# Planning

This section records goals, roadmaps, initiatives, proposals, decisions, experiments, and open questions.
A plan expresses intention; it does not prove completion or authorize every proposed change.

## Current state — 2026-11-11

Planning material is plentiful but dispersed among GitHub issues, specifications, archived proposals, and conversations.
Some documents contradict newer decisions. Active, parked, proposed, superseded, and implemented work must be distinguished before anything is presented as the current plan.
Not every preserved ambition is a delivery commitment.
