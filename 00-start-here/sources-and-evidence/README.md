# Sources and Evidence

> **Status:** Draft — proposed guidance for human review.

This page concerns how Atlas can make factual claims traceable. Prefer direct, relevant sources—such as current repository files, recorded decisions, or dated operational evidence—and link to the exact source when practical. Add dates when information can change.

Separate what a source directly shows from an interpretation, recollection, assumption, or aspiration. State uncertainty instead of smoothing it away, and avoid copying material that has a more authoritative home elsewhere. Never put credentials or other secrets in Atlas.

## Current state

Atlas does not yet have an agreed evidence-ranking system. These are proposed habits for making claims easier to check, not a formal research standard.
