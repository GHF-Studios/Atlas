# Sources and Evidence

- **Sources:** current files/config/code · dated decisions/plans · operational records · recollection
- **Distinguish:** direct evidence · interpretation · remembered claim · assumption · aspiration
- **Date:** changing facts; link to exact source when practical
- **Do not infer:** plan ⇒ implementation · source tree ⇒ successful runtime/release · recollection ⇒ exact chronology
- **Never store:** credentials or secrets
- **Status:** no evidence-ranking system adopted
