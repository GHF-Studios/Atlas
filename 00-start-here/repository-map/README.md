# Repository Map

> **Status:** Draft — proposed guidance for human review.

This page explains the intended responsibility of Atlas’s sections: what kind of knowledge belongs in each place, where topics overlap, and when one page should link to another instead of repeating it.

The [Table of Contents](../../TABLE_OF_CONTENTS.md) is the clickable tree of paths. The repository map should explain the reasons behind those paths, not duplicate the tree. When a topic crosses boundaries, place its main explanation with the closest owner and link to it from related sections.

## Current state

The section boundaries are still being reviewed. These placement ideas are guidance for discussion, not a settled taxonomy or a rule that every topic must fit neatly in one place.
