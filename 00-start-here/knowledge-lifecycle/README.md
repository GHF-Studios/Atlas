# Knowledge Lifecycle

- **Possible path:** capture → identify topic/source → draft in owning folder → human review → maintain, supersede, or retire
- **Presence rule:** a file existing in Git does not establish its claims
- **Distinct from:** [document status](../document-statuses/README.md) (state at a point in time) · [contribution process](../contribution-process/README.md) (discussion of a change)
- **Current reality:** lifecycle and promotion process not formally adopted
