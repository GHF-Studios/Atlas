# Knowledge Lifecycle

> **Status:** Draft — proposed guidance for human review.

This page considers how information might move from an uncategorized note to a useful, maintained part of Atlas, and how outdated material can be corrected, superseded, or retired.

A lightweight path could be: capture the information; identify its topic and evidence; draft it in the right place; invite relevant human review; then revisit it when its sources or context change. A file’s presence in the repository does not by itself make its claims established.

## Boundaries and current state

This page describes possible stages over time. [Document Statuses](../document-statuses/README.md) describes labels for a page at a point in time; the [Contribution Process](../contribution-process/README.md) concerns how a proposed edit is discussed. No lifecycle or promotion process has been formally adopted.
