# Inbox

> **Status:** Draft — proposed purpose for human review.

The inbox is a temporary landing place for notes, links, or questions that do not yet have a clear home in Atlas. Add enough context to understand why an item matters and where it came from, when that is known.

It is not a task backlog, a decision log, or an authoritative source. Once an item is understood, move it to the appropriate topic, record it in the relevant planning system, or discard it if it is no longer useful.

## Current state

No separate inbox workflow has been adopted, and this page does not establish one. The folder is available as a possible capture point; it is not evidence that material is currently being triaged.
