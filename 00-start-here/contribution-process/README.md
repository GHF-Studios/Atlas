# Contribution Process

> **Status:** Draft — proposed guidance for human review; no formal process is adopted.

This page is about proposing and reviewing changes to Atlas documents. It is separate from the [knowledge lifecycle](../knowledge-lifecycle/README.md), which describes how information may mature over time, and from broader organizational governance or engineering review.

A lightweight contribution route could explain the reason for a change, link relevant evidence, identify uncertain or proposed claims, and invite review from someone familiar with the topic. The exact route—direct edits, issues, pull requests, or another approach—still needs a decision.

## Current state

Atlas is a small, founder-led effort. This page must not be read as a requirement for heavyweight approvals or as a description of a process that is already operating.
