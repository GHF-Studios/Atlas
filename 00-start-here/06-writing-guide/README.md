# Writing Guide

- **Drafting preference:** concise topic bullets; expand only when explanation needs it
- **Lead with:** question/topic · scope · observed state · useful links
- **Separate:** observed · inferred · decided · intended · unknown
- **Style:** plain language; narrow scope; evidence links; explicit uncertainty
- **Avoid:** mandatory template, repeated prose, boilerplate, unsupported certainty
- **Status:** guidance only; no required format adopted
