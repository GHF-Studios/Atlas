# Reading Guide

> **Status:** Draft — proposed guidance for human review.

This page helps readers use Atlas without mistaking an empty placeholder, an aspiration, or an unreviewed draft for an established position.

## A practical route

1. Read the [Atlas introduction](../../README.md) for the repository’s purpose.
2. Use the [Table of Contents](../../TABLE_OF_CONTENTS.md) to find a topic.
3. Read that section’s README for its scope and current state, then follow links to relevant details and sources.

You can start with the question you have; Atlas is not a course that must be read from beginning to end. Check dates and status statements where claims may have changed.

## Current state

Atlas is incomplete and still being organized. This is a suggested reading approach, not a requirement or evidence that every page has been reviewed.
