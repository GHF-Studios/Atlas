# Topic Placement

The [Table of Contents](../../TABLE_OF_CONTENTS.md) shows where pages live. This guide helps answer a different question: where should a new Atlas topic go? Start with the section that owns the question being answered, not the repository that happens to contain related code.

For example, instructions for reading or contributing to Atlas belong in `00-start-here/`. Atlas as a product—its purpose, design, and current state—belongs under `03-products/atlas/`. The list of software repositories lives in the [Repository Index](../../08-reference/repository-index/README.md). These subjects are related, but each answers a different question.

Some topics cross section boundaries. A useful starting point is to give the main account one home and link to it from related sections. If no section clearly owns a topic, record that uncertainty instead of copying the same material into several places. The current boundaries are still being reviewed; this is guidance for choosing a home, not a settled taxonomy.
