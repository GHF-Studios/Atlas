# Start Here

> **Status:** Draft — intended for human review.

Atlas is GHF Studios' human-maintained knowledge base. This folder is the **reading and writing guide** for Atlas: how to find information, capture ideas, distinguish evidence from intentions, and improve documents over time.

It is **not** the complete table of contents. That lives in the repository root: [Table of Contents](../TABLE_OF_CONTENTS.md).

## Your first three stops

1. Read the [root README](../README.md) to understand **why Atlas exists**.
2. Open the [Table of Contents](../TABLE_OF_CONTENTS.md) to see **what Atlas covers**.
3. Visit a section's `README.md` to understand **what belongs there and what is actually established**.

You do not need to read or complete everything. Most files are intentionally placeholders: they name questions worth eventually answering, **not** policies already agreed upon.

## Working principle

**Write something imperfect, label it accurately, and improve it when you learn more.**

An empty file can be a useful reminder. A speculative paragraph can be useful research. Neither should be mistaken for an approved decision or verified implementation.

## Current reality

As of November 2026, this navigation system is being designed, not operated as a mature documentation program. The guides above are mostly scaffolding. Nothing here mandates heavyweight reviews, approvals, or process for a pre-alpha, founder-led project. The goal is to make human authorship easier—not to make writing feel like paperwork.
