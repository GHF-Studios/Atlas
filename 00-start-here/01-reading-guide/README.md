# Reading Guide

Start with what you want to understand. The [root README](../../README.md) explains Atlas's purpose; the [clickable folder tree](../../TABLE_OF_CONTENTS.md) helps you find the relevant topic. Read that folder's README first, then follow into details that help answer your question.

Treat Atlas as a guide to the studio's understanding, not as the implementation itself. When a page describes code or current behavior, follow its cited primary sources and check their dates. A plan does not prove implementation, and a source tree does not prove that something runs. See [Sources and Evidence](../03-sources-and-evidence/README.md) for more on those distinctions.

A stated document status can tell you whether a page is a draft, but it does not make the page's claims true or adopted. The status labels are still proposed, not used consistently across Atlas; see [Document Statuses](../04-document-statuses/README.md).

Numeric prefixes establish the intended chapter sequence for a future mdBook. They let you read Atlas as a book, but do not require you to read it linearly; start wherever your question takes you.

Atlas is still being reviewed. A page's presence or its links are not evidence that its content has been checked.
