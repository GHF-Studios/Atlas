# Writing Guide

> **Status:** Draft — proposed guidance for human review.

This page offers a light way to start useful Atlas documents. Begin with the question the page should answer. Keep its scope narrow, use plain language, and distinguish observed facts, interpretations, decisions, and future intentions. Link to authoritative sources where possible and mark uncertainty when evidence is incomplete.

A page should be as short as its purpose allows. Add headings or examples when they help someone find or understand the answer; there is no approved mandatory template.

## Current state

These are suggested writing habits, not an adopted style policy. Atlas has no approved document template or required format.
