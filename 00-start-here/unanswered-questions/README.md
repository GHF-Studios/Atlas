# Unanswered Questions

> **Status:** Draft — proposed scope for human review.

This page is a home for unresolved questions about Atlas itself: its structure, navigation, writing conventions, evidence practices, and maintenance. It is not a catch-all for open questions about products or studio plans; keep those with the topics they concern.

When useful, record why a question matters and link to the discussion or evidence that raised it. Remove or mark questions once they are answered, deferred, or no longer relevant.

## Current state

This page defines a possible boundary for an Atlas-specific question list. It is not yet a complete register, and no tracking process has been adopted.
