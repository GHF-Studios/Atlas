# Contribution Process

- **Purpose:** propose and review Atlas document changes
- **Separate from:** [knowledge lifecycle](../05-knowledge-lifecycle/README.md) (page maturity) · Organization (governance) · Engineering (code review)
- **Useful change context:** reason · evidence links · uncertain/proposed claims · topic-aware reviewer
- **Unsettled:** direct edits vs issues vs pull requests; who approves which changes
- **Current reality:** no formal Atlas review process recorded; keep any workflow lightweight
