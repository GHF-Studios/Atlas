# Organization

This section describes who owns decisions, how we work together, and how contributors can understand and participate in GHF Studios.

## Current state — 2026-11-11

This is primarily a founder-led, AI-assisted effort—not an established multi-team organization.
Responsibilities are often visible in code and plans, but a fully articulated human governance model and mature contributor community do not yet exist.
Processes should reflect our actual size and stage while preparing for more human collaboration.
