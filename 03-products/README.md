# Studio Portfolio

This section describes the studio's products and major projects: their purpose, current capabilities, limitations, and relationships to one another.
Detailed implementation truth remains in the relevant source repository.

## Current state — 2026-11-11

- **Vapor:** substantial Rust tooling, application surfaces, and services exist; installation, composition, and distribution are still being reworked.
- **Spacetime Engine:** a genuine Bevy-based simulation codebase with multiscale spatial, voxel, physics, and developer systems; not yet the complete general-purpose universe engine envisioned.
- **Loo Cast:** a meaningful technical/gameplay proving ground, not yet a complete game experience.
- **Atlas:** being reset to a human-authored documentation repository; its previous generated site and knowledge model are no longer the intended foundation.

Product visions and implementation status must remain separate.
