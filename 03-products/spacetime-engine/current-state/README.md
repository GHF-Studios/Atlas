Spacetime Engine is a real Rust 2024 and Bevy ECS codebase used by Loo Cast. Its documented source areas include configuration, ECS, spatial state, experimental sparse world-rule evaluation, voxel materialization, physics, geometry, developer tools, diagnostics, and Game adapters.

The README describes a Celestial Fixture with explicit Sun/Earth/Moon content. It does not claim a generated galaxy, ecology, or atmosphere. Automated test targets and executable doctests are disabled; behavior changes are expected to be inspected in a relevant scene and the observed result recorded.
