# Atlas Knowledge Base

> **Status:** Draft — product description for review; Atlas is still being structured.

Atlas is GHF Studios' human-authored knowledge base: Markdown organized in a repository so people can preserve ideas, decisions, designs, technical understanding, and history. The source repository is the editable record; the published site is a derived reading surface.

Use this branch for Atlas's product model, information architecture, publishing boundaries, and intended reader and author experience. The root README and `00-start-here/` explain how to use this particular repository; shared studio guidance belongs elsewhere.
