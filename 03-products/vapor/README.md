# Vapor Platform

> **Status:** Draft — product boundary summarized from the current Vapor Client and Platform Server documentation.

Vapor is the studio's platform layer for generic Engines, Games, Mods, packs, authoring, validation, launching, and distribution. Its user-facing applications are separate products and repositories over shared Vapor Client services; the Platform Server and Registry provide distinct server-side responsibilities.

The target content catalog, composition resolver, and native-build workflow are not all implemented. Keep accepted target semantics, current code, and future workflow plans visibly separate throughout this branch.
