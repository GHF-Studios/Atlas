# Product Roles

> **Status:** Draft — role definitions follow the accepted typed-content model.

Define Engine, Game, Packagepack, and Mod as roles of Vapor content and state what each role allows a resolver or tool to do. These roles do not imply one another: a Packagepack is not inherently a Game or Project, and a Game need not be delivered as a Packagepack.

Registry typed role records are not implemented yet; use the accepted contract and label them as target semantics.
