# Concepts

> **Status:** Draft — shared Vapor domain terms; respect accepted contracts and implementation gaps.

Define the distinctions Vapor relies on across content, workspace, distribution, identity, and execution. Several distinctions are already explicit in the Platform Server domain contract; use that contract as the starting authority and mark target-only concepts.

Do not collapse Projects, content identities, releases, acquisition bindings, compositions, application releases, and build snapshots into one generic package concept.
