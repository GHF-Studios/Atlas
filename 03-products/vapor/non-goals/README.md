# Non-Goals

> **Status:** Draft — accepted boundaries exist; consolidate their canonical source.

Preserve explicit product boundaries such as: GitHub is not required for players; Steam Workshop is a provider, not Vapor's content catalog; proprietary depot bytes are not uploaded to Vapor; a build snapshot is not an application release; and a shared compiler cache is not required for local build correctness.

Link to the server domain contract as the authority and avoid maintaining a divergent second policy list here.
