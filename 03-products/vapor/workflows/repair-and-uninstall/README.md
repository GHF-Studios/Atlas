# Repair and Uninstall

> **Status:** Draft — use the current Installer contract for exact actions and preservation rules.

Describe how a user inspects Vapor-owned paths, repairs the app root, removes machine integration, or explicitly requests full erasure. Full erasure requires an exact confirmation and an external helper after the installer exits.

Preserve Vapor Home on ordinary uninstall and preserve Steam files and user-managed Rust/Cargo installations outside the canonical Vapor roots.
