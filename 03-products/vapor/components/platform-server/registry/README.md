# Registry Service

> **Status:** Draft — distinguish the Registry service from the Vapor Registry authority repository.

The deployed `Vapor-Registry-Server` service currently owns ecosystem/source topology and visibility policy. The typed content catalog, Workshop bindings, release metadata, composition resolver, and publishing decisions are accepted target work, not implemented current storage.

The separate `Vapor-Registry` repository owns the canonical domain and policy work; verify its current state before changing this account.
