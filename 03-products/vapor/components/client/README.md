# Client

> **Status:** Draft — component role grounded in the Vapor Client README.

Vapor Client is the source tree for the standalone Vapor runtime and its tools. It owns the intended separate installation/update lifecycle, shared app-root and client service operations, developer environment, local caches, and mutable Vapor state.

The move of current Vapor installation and state out of the Steam directory is still in progress. Loo Cast Steam packaging remains a separate product boundary.
