# State and Lifecycle

> **Status:** Draft — source, package, and installation lifecycles are separate.

Describe how the three source-controlled content artifacts are changed, validated, packaged, staged, and delivered. The Loo-Cast workflow documents `content validate`, package construction, and a dry-run publication preview; real Steam publication remains a separate explicit action.

The Steam-installed app and mutable Vapor runtime state have separate owners. Do not imply that a staged or validated package has been published or installed.
