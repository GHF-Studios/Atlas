# Reference

This section gives readers dependable definitions, conventions, indexes, and links to authoritative technical material.

## Current state — 2026-11-11

Much reference material already exists across Vapor documentation, repository READMEs, code, and historical glossaries, but it is not one coherent vocabulary.
Some terms have changed meaning or authority over time. Atlas should define terms carefully and link to their real owners, rather than silently copy old definitions into a new canon.
