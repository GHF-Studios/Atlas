# Ecosystem Overview

The ecosystem is the connected work around making, supporting, distributing, and using GHF Studios’ products: projects and content, Vapor tooling and runtime, shared services, external systems, people, and the paths between them. It is not one finished platform; each part has its own responsibilities and authority.

The central product story connects Vapor’s evolving glue and tooling, the more bounded Spacetime Engine concept, and Loo Cast as the game intended to use it. A repository can contain work for more than one part, so repository boundaries do not by themselves define product boundaries. The [Product Map](../03-product-map/README.md) and [Product Relationships](../04-product-relationships/README.md) examine those distinctions.

This page frames the map rather than asserting that every connection is complete or live. See [Current State](../02-current-state/README.md) for evidence about what works today and [System Boundaries](../07-system-boundaries/README.md) for where responsibilities begin and end. Public repositories and configured integrations do not, by themselves, establish a published workflow or an external creator community.
