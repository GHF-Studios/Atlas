# Ecosystem

This section explains how GHF Studios' products, tools, content, infrastructure, and people relate to one another—and where their responsibilities differ.

## Current state — 2026-11-11

There are real, interconnected repositories and working integration paths.
Vapor provides the general-purpose platform; Spacetime Engine and Loo Cast provide demanding first-party use cases; Atlas is being restarted as human-authored knowledge.
However, product boundaries and distribution workflows are still changing.
Public source repositories are **not** evidence of an established third-party creator ecosystem or community.
