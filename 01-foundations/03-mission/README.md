# Mission

- **Our work:** We build Vapor as the glue and evolving tooling; develop the Spacetime Engine as a concrete engine whose contract we aim to implement fully; and build Loo Cast as a first-party game that uses it. See the [Studio Portfolio](../../03-products/README.md) for each project's scope and current state.
- **How this serves our purpose:** We put what we already believe possible into practice. Loo Cast is meant to show the Engine in use; persuading critics is not the goal.
- **Current reality:** The repos contain substantial Vapor tooling and services, a real Spacetime Engine codebase, and Loo-Cast product-content placeholders. The Engine contract and complete game experience remain unfinished; these ambitions are not claims of completed products.
- **Who this serves:** Still open: who beyond us is this work for, and what should they gain from it?
