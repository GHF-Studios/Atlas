# Values

We have not yet written down a studio-wide set of values we affirm. Earlier candidate themes—creative freedom, curiosity, agency, evidence, and maintainability—were inferred from project structure, not chosen by us; do not treat them as our values.

For this page, values are what matter enough to shape hard choices. The related pages answer different questions: [Purpose](../02-purpose/README.md) explains why we commit, [Convictions](../07-convictions/README.md) records what we believe to be true, and [Principles](../11-principles/README.md) describes how we choose to act. These are working boundaries, not airtight categories.

**Still open:** What do we genuinely value, and what are we unwilling to trade away when priorities conflict?
